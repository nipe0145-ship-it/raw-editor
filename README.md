# RAW 편집 (웹 버전)

사진을 열어 보정하고 원본 해상도 JPEG 로 내보내는 개인용 사진 편집기. 라이트룸 모바일과 비슷한 화면이다.
Sony a7C 의 RAW(ARW)와 JPEG·PNG·WebP 를 연다.

**바로 쓰기: https://nipe0145-ship-it.github.io/raw-editor/**

- 보관함: 여러 장 가져오기, 앨범, 길게 눌러 여러 장 고르기
- 보정: 노출·대비·영역별 밝기, 톤 곡선(전체·빨강·초록·파랑), 색온도·색조·생동감·채도, 색상 혼합, 자르기·각도·원근, 마스킹(선형·방사형·브러시), 노이즈 감소
- 설정 복사·붙여넣기, 실행 취소
- 자동 저장: 보정 값과 가져온 사진은 이 브라우저 안(IndexedDB)에만 저장된다. 어디로도 올라가지 않는다.

파일 하나(`index.html`, 외부 라이브러리 없음)로 되어 있다. WebGL2 를 지원하는 브라우저가 필요하다.
